# Wassup Ed-boys.

I'm a hobbyist programmer who codes for the love of the game. I program anything that peeks my interest, mostly game development and reverse engineering. I have no interest in network/web development.

### Language of choice?
Anything but C++ or Javascript 🤢. I like learning new languages and tools, I can easily move between them depending on my goal.
- Odin - My favorite language for general-purpose low level programming, and long term projects.
- SDL3/SDLGPU - My framework of choice for performance critical engines.
- Raylib - My framework of choice for simple engines.
- Godot - Prototyping with 2D/3D graphics and GUI.
- Python - Quick scripts for building things asap.
- C# - Contributing to community projects. And for long term projects.
- ImHex Pattern - For turning binaries into a readable structure. Check out some [pattern scripts](https://ssx.computernewb.com/wiki/Formats) I helped create.
- C, F#, Rust, ARM7TDMI, and Gameboy Assembly - Experimental.

### What am I actively working on?
My Magnum Opus is the [Hard Time port](https://github.com/Erickson400/Hard-Time), translating the old fella into a modern graphics API, finally making it run natively to scratch my nostalgic itch, hopefully finished in 2 years. 

My second active project is the [SSX-Library](https://github.com/GlitcherOG/SSX-Library). A tool for facilitating modding for [SSX games](https://en.wikipedia.org/wiki/SSX). I'm not the lead dev but I contribute and aid on its development here and there.
